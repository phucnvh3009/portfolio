## 📌 Giới thiệu dự án

Website Portfolio cá nhân được xây dựng với mục tiêu giới thiệu bản thân, kỹ năng kỹ thuật, các dự án tiêu biểu và quy trình làm việc chuẩn mực (Git Flow, Agile/Scrum).

### ✨ Các tính năng nổi bật:
- 📱 **Responsive Design 100%:** Tối ưu hiển thị mượt mà trên Mobile, Tablet và Desktop.
- 🌓 **Dark / Light Theme:** Chuyển đổi giao diện sáng/tối linh hoạt với lưu trữ trạng thái qua LocalStorage.
- 🎯 **Lọc danh mục dự án (Project Filtering):** Phân loại theo *Tất cả*, *Web Application*, *Frontend UI*, *Công cụ*.
- 🔍 **Cửa sổ chi tiết dự án (Interactive Modal):** Bấm vào bất kỳ dự án nào để xem chi tiết tính năng, công nghệ sử dụng và link demo/mã nguồn. Hỗ trợ phím tắt `ESC` để đóng.
- ✉️ **Contact Form UI:** Xác thực dữ liệu nhập và hiển thị Toast Notification khi gửi thành công.
- 📸 **Hình ảnh chân dung chính chủ:** Đảm bảo đúng tiêu chuẩn tính độc bản của bài nộp.

---

## 🛠️ Công nghệ sử dụng
- **HTML5 Semantic:** Cấu trúc tài liệu chuẩn SEO, tối ưu khả năng tiếp cận (Accessibility).
- **CSS3 Modern:** CSS Variables (Design Tokens), Flexbox, CSS Grid, Glassmorphism, Animation chuyển động.
- **Vanilla JavaScript (ES6+):** Xử lý toàn bộ logic động, không phụ thuộc vào thư viện ngoài nặng nề.
- **Font Awesome 6 & Google Fonts (Plus Jakarta Sans, JetBrains Mono)**.
- **GitHub Pages:** Triển khai và lưu trữ website trực tuyến miễn phí.

## 🚀 Hướng dẫn mở dự án ở máy cục bộ (Local)
1. Clone repository về máy:
   ```bash
   git clone https://github.com/phucnvh3009/portfolio.git
   ```
2. Vào thư mục:
   ```bash
   cd portfolio
   ```
3. Mở tệp `index.html` trực tiếp trên bất kỳ trình duyệt nào (Chrome, Edge, Firefox...).
